Attribution and asset licenses

The upstream repository remains intact at base commit a192410e27ea345644ae5c4b29b4c9c40cbe1a73, branch Voron2.4. Its original CAD, STLs, PDF, README attribution and GPL-3.0 LICENSE are preserved. There was no editable Markdown/InDesign manual source in the inspected tree; the custom source is maintained Markdown rather than a modified extracted PDF.
